# BANG! 遊玩說明

## 開始遊戲

- **單機**：在大廳選人數（4–7 人，勾選道奇城可以 8 人）、勾選要加入的擴充、選**電腦難度**（簡單／普通／困難），按「開始單機遊戲」，其他位子由電腦玩家補上。座位每局隨機。
- **和朋友連線**：按「建立房間」，把邀請連結傳給朋友。朋友打開連結、輸入名字就能加入，任何網路都可以。人不夠時由電腦補位；有人斷線會先等 15 秒，之後由電腦代打，重新連上就還給他。
- 連線房間裡，房主也可以選電腦難度。房間裡可以打字聊天，也可以開語音。
- **語言**：大廳和遊戲上方的語言選單可以隨時切換中文、English、Tiếng Việt（越南文），記在這台裝置上；連線時每個人可以用自己的語言。英文和越南文的牌名、角色名、事件名沿用官方英文版。

## 身份與勝利條件

開局每人抽一張身份牌，只有**警長**公開。

| 身份 | 勝利條件 |
|---|---|
| 警長 | 消滅所有歹徒和叛徒 |
| 副警長 | 保護警長，消滅所有歹徒和叛徒 |
| 歹徒 | 殺死警長 |
| 叛徒 | 成為最後一個活著的人（最後要單挑贏警長） |

| 人數 | 身份 |
|---|---|
| 4 | 警長、叛徒、歹徒 ×2 |
| 5 | 警長、副警長、叛徒、歹徒 ×2 |
| 6 | 警長、副警長、叛徒、歹徒 ×3 |
| 7 | 警長、副警長 ×2、叛徒、歹徒 ×3 |
| 8（道奇城） | 警長、副警長 ×2、叛徒 ×2、歹徒 ×3 |

開局有一個**選角畫面**：這局開放的角色（依勾選的擴充包決定）全部攤開，每張都寫著生命和能力。大家同時挑，別人選了誰會發光並標上名字。

- 兩個人選了同一個角色：各擲一枚硬幣，人頭的拿到（都人頭或都反面就重擲）。
- 三人以上撞角：每人擲 3 枚，人頭最多的拿到，平手的人再擲。
- 沒拿到的人從剩下的角色再選一輪。

生命值看角色（大多是 4，有些是 3，大斯賓瑟 9、蓋瑞 5），警長再 +1；開局手牌數等於生命值。

## 一回合的流程

1. **抽牌**：抽 2 張（有些角色不一樣）。回合開始時如果面前有炸藥或監獄，要先抽判定。
2. **出牌**：想出幾張都可以，但「砰！」每回合只能出一張（火山連發槍、小子威利例外）。場上同名的裝備只能有一張，武器只能有一把。
3. **棄牌**：手牌不能超過目前的生命值，多的要棄掉。按「結束回合」。

## 距離與射程

- 相鄰的人距離 1，隔一個人距離 2，依此類推（往左或往右取近的那邊，死掉的人不算）。
- 「砰！」只能打射程內的人。沒裝武器時射程 1，武器決定射程。
- 野馬讓別人看你遠 1，瞄準鏡讓你看別人近 1。
- 名牌上的「距離」標紅色，就代表他在你的射程內。

## 擴充

### 道奇城

多 40 張牌、15 位角色，可以 8 人玩。

- **綠牌**：打出時先放到場上，**下一回合起**才能用（棄掉它來發動）。名牌上虛線框的綠牌代表還不能用。
  - 聖經、十加侖帽、鐵板、墨西哥帽：被開槍時當作「射偏了！」（聖經還會抽 1 張）。
  - 小刀、德林傑：打距離 1；胡椒盒手槍：打射程內；野牛步槍：不限距離。
  - 水壺回 1 血、康康舞＝卡特巴洛、篷車＝不限距離的搶奪、榴彈砲＝格林機槍、驛馬快遞抽 3 張。
- **要另外棄 1 張手牌的牌**：拉格泰姆（不限距離搶一張）、鬥毆（每人被你棄一張）、春田步槍（不限距離開槍）、龍舌蘭（任一人回 1 血）、威士忌（自己回 2 血）。
- 拳擊：打距離 1，不算「砰！」次數。閃躲：當作射偏了再抽 1 張。望遠鏡＝瞄準鏡、藏身處＝野馬。

### 正午、一把卡牌、西部秀（事件）

警長從第二個回合起，每次回合開始翻一張事件牌，效果持續到下一張翻開為止。畫面左下會顯示目前的事件，桌上也會放著事件牌。事件牌堆最下面是結局牌（「正午決戰」每人回合開始失去 1 點生命；「一把卡牌」手上幾張牌就挨幾槍）。

### 淘金熱

- 每讓別人失去 1 點生命，你就得到 1 **金塊**。也可以把手上的啤酒換成 1 金塊。
- 出牌階段下方會出現**商店**（翻開 3 張裝備）：
  - 棕框裝備買了立刻使用（小酒杯、酒瓶、搭檔、淘金熱、蘭姆酒、聯合太平洋）。
  - 黑框裝備放在你面前（馬蹄鐵、十字鎬、靴子、幸運符、背包、子彈帶、和平菸斗、淘金盤，還有可以貼在別人身上的通緝令）。
- 付「價格 + 1」金塊可以棄掉別人的黑框裝備；搶奪、卡特巴洛動不了它們。

### 幽谷

多 15 張牌和 8 位角色：瞄準（打中失去 2 點）、連開（一次打兩個相鄰的人）、印第安戰斧（距離 2）、回火（躲開並反擊）、逃脫（躲開棕牌效果）、土匪、撲克、龍捲風、最後一杯，裝備有勒馬特（任何牌當砰！）、霰彈槍、響尾蛇、懸賞，還有能讓死去的人以幽靈身分回來的「幽靈」。

### 西部秀

8 位新角色和一副事件牌（墓園、親愛的瓦倫丁、海倫娜、蘇珊娜小姐、對決、薩卡加維亞），結局牌「西部秀」把所有人的目標都變成「成為最後一個活著的人」。

## 死亡與獎懲

- 生命歸零時可以馬上喝啤酒自救；救不回來就死亡，公開身份。
- 擊斃歹徒的人抽 3 張牌獎勵。
- 警長誤殺副警長，要棄掉所有手牌和裝備。

## 畫面怎麼看

遊戲一開始是**第一人稱視角**：你坐在自己的位子上，看得到自己的手牌，拖曳畫面可以轉頭。按右下角「切換到俯瞰視角」可以從上方看整張桌子。

- 每個人手上拿著的牌數，就是他的手牌數。
- 名牌上有生命（子彈）、距離、場上裝備。點名牌上的角色名稱（或上方「角色能力」）可以看每個人的角色能力、生命和每件裝備的效果。
- 裝備會擺在那個人面前的桌上，有對應的小道具（手槍、長槍、望遠鏡、木桶、馬蹄鐵、炸藥…）和大家都看得到的名牌，武器會標出射程。
- 被關進監獄的人會有一個鐵籠從天而降罩住他；如果是你，畫面前面會出現一排鐵欄。
- 有人開槍時，他會拔出左輪手槍、甩出轉輪一發一發裝上子彈、合上轉輪、扳起擊錘，再對準目標開火（每個步驟都有音效）；格林機槍這種連發不會中途重裝。躲開會跳出「射偏了！」，中彈會閃紅。你自己開槍時，第一人稱畫面會看到自己的手在眼前裝彈；你中彈時畫面邊緣會閃紅。
- 遊戲有音效，上方「音效 開／關」可以切換。

## 操作

- **出牌**：點一張手牌，下面會出現可以選的目標，點目標就打出。搶奪和卡特巴洛還要選對方的哪一張牌；需要代價的牌會再請你點選要另外棄的手牌。
- **場上的綠牌**：輪到你時下方會出現「場上的綠牌」按鈕，點一下再選目標。
- **角色能力**：可以主動發動的能力（席德、恰克、荷西、霍利戴）會出現在下方按鈕。
- **被開槍**：點亮的「射偏了！」直接點下去就能躲；有木桶會出現「用木桶抽判定」按鈕。
- 連線時每個決定有時間限制，時間到會由電腦幫你做。

## 電腦怎麼猜身分

電腦玩家**不會偷看**。它拿到的資料和你畫面上的一樣，從頭到尾只能靠「大家看得到的行為」去猜誰是哪一邊。它不是看一個分數高低就決定打誰，而是像真人一樣：先猜每個人**可能**是什麼身分，再看有沒有把握、對方有沒有打過自己、是不是快死了，才決定要不要開槍。

### 電腦知道什麼

- 自己的身分。
- 誰是警長（本來就公開）。
- 已經死掉的人的身分（死亡時翻開；被「幽靈」救回來的也一樣）。
- 每種身分總共幾個人（例如 7 人局：1 警長、2 副警長、3 歹徒、1 叛徒），所以算得出「還有幾個歹徒沒現身」，但不知道是誰。

不知道：活著的其他人的身分、別人的手牌（除非「薩卡加維亞」事件把手牌公開，那時大家都看得到）。

### 第一步：記下「誰對誰做了什麼」

每次有人**指定某個人**做事，就記一筆公開的「互動」。正數代表敵意，負數代表幫忙，數字代表這件事有多明確：

| 行為 | 權重 |
| --- | --- |
| 砰！、決鬥、拳擊、春田步槍、小刀、德林傑、胡椒盒手槍、野牛步槍、印第安戰斧、「狙擊手」事件的雙砰！、黑花把梅花當砰！，霍利戴醫生／傑基／伊芙琳等角色能力開的槍 | +1 |
| 連開（一次打兩個）：兩個目標各記 | +1 |
| 瞄準（打中失去 2 點） | +1.3 |
| 監獄 | +0.8 |
| 響尾蛇 | +0.7 |
| 懸賞、通緝令 | +0.6 |
| 搶奪、卡特巴洛、篷車、拉格泰姆、用砰！射場上的牌、花金塊棄別人的裝備 | +0.6 |
| 派特．布瑞南拿別人場上的牌 | +0.5 |
| 回火（被打才還手） | +0.5 |
| 傑西．瓊斯抽別人手牌、佛林特換牌 | +0.3 |
| 亨利．布洛克被動回敬一槍 | +0.3 |
| 鬥毆（大家都得棄牌）中被挑的那張 | +0.2 |
| **格林機槍、榴彈砲、印第安人（全場都打）**：每個人各記 | +0.15 |
| 同上，但那個人只剩 1 點生命（可能被你打死） | +0.6 |
| 打死一個人（額外再加） | +1.5 |
| 拿走或棄掉別人面前的**監獄** = 救他 | −0.6 |
| 拿走或棄掉別人面前的**炸藥** = 幫他 | −0.3 |
| 請別人喝酒（龍舌蘭、小酒杯）、血親給血 | −1 |
| 用「幽靈」讓死掉的人回來 | −1 |

**完全不算的行為**（沒有指定對象，或不是自己能選的）：土匪、撲克、龍捲風、酒館、雜貨店、自己喝啤酒、炸藥自己傳下去、事件牌的效果、抽判定、尤爾．葛林納逼別人給牌、禿鷹山姆撿遺物、抽牌類能力。

### 第二步：每台電腦自己猜每個人的身分（機率）

每個電腦玩家對每個看不到身分的人，估計他是**副警長／歹徒／叛徒**的機率。

1. **起點是人數。** 例如 7 人局、我是歹徒：其他 5 個看不到身分的人裡有 2 個副警長、2 個歹徒、1 個叛徒，所以每個人一開始都是「副警長 40%、歹徒 40%、叛徒 20%」。
2. **每個行為都是一條線索。** 電腦會問：「如果他是副警長（或歹徒、叛徒），做這件事的可能性有多高？」可能性越高，那個身分的機率就往上調。

   | 他做了什麼 | 像副警長 | 像歹徒 | 像叛徒 |
   | --- | --- | --- | --- |
   | 打警長 | 幾乎不會（3%） | 很常（100%） | 偶爾（25%） |
   | 打一個「像歹徒」的人 | 很常（100%） | 很少（20%） | 常（90%） |
   | 打一個「像副警長」的人 | 很少（25%） | 常（85%） | 一半（55%） |
   | 幫警長（請喝酒、拆監獄） | 很常 | 幾乎不會 | 常 |
   | 幫一個「像歹徒」的人 | 很少 | 很常 | 偶爾 |

   權重越大的行為影響越大；格林機槍這種全場攻擊每人只有 0.15，幾乎不會改變判斷。
3. **被誰打也是線索。** 被警長打 → 警長懷疑他，比較像歹徒（但警長也會看錯，所以只是弱線索）。被「像歹徒」的人打 → 他比較像好人。這類線索只算一半。
4. **電腦知道自己的身分。** 所以「誰打了我」對它來說也是線索：我是副警長，有人一直打我，那個人比較像歹徒。
5. **人數推算。** 歹徒只剩 2 個沒現身，就不可能有 4 個人都「很像歹徒」；機率會一起調整，加起來要符合人數。
6. **有人死掉翻開身分時，整局重新推算。** 以前打過他的人會跟著重新評價：一直打某人、他死後翻開是歹徒，那個人就很像副警長。

**大家都沒動作時**，每個人都停在起點的機率，沒有人特別可疑，電腦也就不會因為「分數」去亂打（見下一步的門檻）。

### 實際例子

7 人局，座位 1 是警長。以下數字都是程式實際算出來的（困難難度）：

| 發生的事 | 從誰的角度 | 對誰的猜測 | 敵人把握 |
| --- | --- | --- | --- |
| 開局 | 歹徒 A | 每個人：副警長 40%、歹徒 40%、叛徒 20% | 39% |
| 歹徒 B 打警長 | 歹徒 A | B：歹徒 81% | −12%（當成同伴，不會打他） |
| 歹徒 B 打警長 | 副警長 C | B：歹徒 89% | 93% |
| 副警長 C 打 B | 歹徒 A | C：副警長 62% | 72% |
| 副警長 C 打 B | 另一個副警長 D | C：副警長 39%（起點只有 20%） | 39% |
| 警長打歹徒 E | 副警長 C | E：歹徒 60% | 67% |
| 歹徒 A 打出格林機槍 | 副警長 C | A：歹徒 52%（只比起點多一點） | 61% |

這就是你擔心的情況的解法：**歹徒 B 打了警長之後，其他歹徒會把他當同伴**，不會因為「他分數很低」去打他。

### 第三步：要不要開槍

1. **把機率換成「他是我敵人的把握」**，每個身分算法不同：
   - **警長、副警長**：歹徒機率 ＋ 叛徒機率 × 0.35（歹徒死光後叛徒就是頭號敵人）。
   - **歹徒**：警長永遠是第一目標；其他人＝副警長機率 ＋ 叛徒機率 × 0.55 − 歹徒機率 × 0.3，越像歹徒越不會打。
   - **叛徒**：前期主要打歹徒、其次副警長；**警長只剩 2 點生命以下時保護他**，只剩自己和警長兩人時才打警長；歹徒死光後所有人都是目標。
   - **西部秀結局事件**：大家都要活到最後，所有人都是敵人。
2. **要有證據才開槍。** 把握必須超過門檻：警長 40%、副警長 50%、歹徒 50%、叛徒 45%，而且還要比「一個完全沒表態的人」本來的機率再高一截（警長 +2%、副警長 +8%、歹徒 +10%、叛徒 +4%）。所以沒有證據時，副警長不會只因為「歹徒人數多」就亂打。回合拖久了門檻會慢慢降低（最多降 30%），避免僵局。
3. **人性的考量：**
   - **記仇**：打過我的人想打的程度會加一點（但如果很確定他是自己人就算了）。
   - **補刀**：敵人只剩 1 點生命時更想打他。
   - **歹徒看到警長**：只要打得到就優先打。
4. **一點隨機。** 每次做決定都會加一點隨機，所以不會每次都一模一樣，難度越低越隨機。
5. **警長試探。** 警長找不到有把握的目標時，有 25% 機率對最可疑的人（歹徒機率至少 45%）開一槍試探。
6. **誰算自己人。** 敵人把握低於 25%（歹徒是 20%）就當自己人：會請他喝酒、幫他拆監獄或炸藥、用「幽靈」救他。

### 難度

| | 簡單 | 普通 | 困難 |
| --- | --- | --- | --- |
| 推理 | 只看「誰打警長、誰打我」，不做連鎖推理和人數推算 | 完整推理 | 完整推理 |
| 隨機程度 | 大 | 中 | 小 |
| 記仇 | 中 | 較重 | 輕 |
| 補刀 | 幾乎不會 | 會 | 很積極 |
| 手滑 | 30% 的回合會失誤，其中一半忘了出牌就結束 | 偶爾 | 不會 |

用電腦對電腦各打幾百局統計：歹徒誤打歹徒的比例從舊版的 8% 降到約 3%，歹徒把火力集中在警長身上（約 70% 的攻擊）。普通難度大約歹徒贏一半、警長方三成多、叛徒一成多；困難難度警長方會更強一點。

### 全場攻擊和其他牌

- 格林機槍、印第安人、鬥毆、土匪、撲克：電腦只在**場上敵人不比自己人少**的時候才會打出，免得誤傷太多。
- 監獄、響尾蛇、懸賞、決鬥、搶奪、卡特巴洛：只對想打的人用。搶奪和卡特巴洛如果找不到目標，會拿去**幫自己人拆掉監獄或炸藥**。
- 酒館：自己或自己人受傷時才打。

### 會猜錯的地方（跟真人一樣）

- 一直沒對人出手的副警長，機率停在起點，歹徒看不出他是誰。
- 叛徒前期會打歹徒，看起來像副警長，歹徒可能把他當副警長打，警長也可能被他騙。
- 射程不夠時，電腦只能打得到的人，不一定是它最想打的人。
- 警長試探性開槍可能打到副警長，那個副警長就會被暫時懷疑。
