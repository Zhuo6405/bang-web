# BANG! 遊玩說明

## 開始遊戲

- **單機**：在大廳選人數（4–7 人），按「開始單機遊戲」，其他位子由電腦玩家補上。
- **和朋友連線**：按「建立房間」，把邀請連結傳給朋友。朋友打開連結、輸入名字就能加入，任何網路都可以。人不夠時由電腦補位；有人斷線會先等 15 秒，之後由電腦代打，重新連上就還給他。
- 房間裡可以打字聊天，也可以開語音。

## 身份與勝利條件

開局每人抽一張身份牌，只有**警長**公開。

| 身份 | 勝利條件 |
|---|---|
| 警長 | 消滅所有歹徒和叛徒 |
| 副警長 | 保護警長，消滅所有歹徒和叛徒 |
| 歹徒 | 殺死警長 |
| 叛徒 | 成為最後一個活著的人（最後要單挑贏警長） |

| 人數 | 身份 |
|---|---|
| 4 | 警長、叛徒、歹徒 ×2 |
| 5 | 警長、副警長、叛徒、歹徒 ×2 |
| 6 | 警長、副警長、叛徒、歹徒 ×3 |
| 7 | 警長、副警長 ×2、叛徒、歹徒 ×3 |

每個人從兩張角色中挑一張。生命值看角色（警長再 +1），開局手牌數等於生命值。

## 一回合的流程

1. **抽牌**：抽 2 張（有些角色不一樣）。回合開始時如果面前有炸藥或監獄，要先抽判定。
2. **出牌**：想出幾張都可以，但「砰！」每回合只能出一張（火山連發槍、小子威利例外）。場上同名的裝備只能有一張，武器只能有一把。
3. **棄牌**：手牌不能超過目前的生命值，多的要棄掉。按「結束回合」。

## 距離與射程

- 相鄰的人距離 1，隔一個人距離 2，依此類推（往左或往右取近的那邊，死掉的人不算）。
- 「砰！」只能打射程內的人。沒裝武器時射程 1，武器決定射程。
- 野馬讓別人看你遠 1，瞄準鏡讓你看別人近 1。
- 名牌上的「距離」標紅色，就代表他在你的射程內。

## 卡牌速查

| 牌 | 效果 |
|---|---|
| 砰！ | 對射程內一人開槍，對方要出「射偏了！」，否則失去 1 點生命 |
| 射偏了！ | 被開槍時打出，躲開這一槍 |
| 啤酒 | 回 1 點生命；瀕死時也可以喝。只剩兩人時無效 |
| 酒館 | 所有人回 1 點生命 |
| 驛馬車／富國快遞 | 抽 2 張／抽 3 張 |
| 雜貨店 | 翻開存活人數的牌，從你開始每人挑一張 |
| 格林機槍 | 對其他所有人各開一槍 |
| 印第安人！ | 其他所有人各棄一張「砰！」，否則失去 1 點生命 |
| 決鬥 | 和任一人輪流棄「砰！」，先棄不出的人失去 1 點生命 |
| 搶奪 | 拿走距離 1 以內一人的一張牌 |
| 卡特巴洛 | 棄掉任一人的一張牌 |
| 木桶 | 被開槍時抽判定，紅心就當作「射偏了！」 |
| 炸藥 | 回合開始抽判定，黑桃 2–9 爆炸失去 3 點生命，否則傳給下一位 |
| 監獄 | 放在警長以外的人面前；他回合開始抽判定，不是紅心就跳過回合 |
| 野馬／瞄準鏡 | 別人看你 +1／你看別人 -1 |
| 武器 | 火山連發槍（射程 1，無限開槍）、史科菲 2、雷明頓 3、卡賓槍 4、溫徹斯特 5 |

**抽判定**：翻開牌堆頂的一張，看它的花色和點數（牌左上角）。

## 死亡與獎懲

- 生命歸零時可以馬上喝啤酒自救；救不回來就死亡，公開身份。
- 擊斃歹徒的人抽 3 張牌獎勵。
- 警長誤殺副警長，要棄掉所有手牌和裝備。

## 畫面怎麼看

遊戲一開始是**第一人稱視角**：你坐在自己的位子上，看得到自己的手牌，拖曳畫面可以轉頭。按右下角「切換到俯瞰視角」可以從上方看整張桌子。

- 每個人手上拿著的牌數，就是他的手牌數。
- 名牌上有生命（子彈）、距離、場上裝備。
- 有人開槍時，他會拔出左輪手槍對準目標開火；躲開會跳出「射偏了！」，中彈會閃紅。你自己中彈時畫面邊緣會閃紅。
- 遊戲有音效，上方「音效 開／關」可以切換。

## 操作

- **出牌**：點一張手牌，下面會出現可以選的目標，點目標就打出。搶奪和卡特巴洛還要選對方的哪一張牌。
- **被開槍**：點亮的「射偏了！」直接點下去就能躲；有木桶會出現「用木桶抽判定」按鈕。
- 連線時每個決定有時間限制，時間到會由電腦幫你做。
